# Текстовый ридер (Android)

Приложение для Android, которое открывает текстовый файл и отображает его
содержимое на экране с вертикальной прокруткой.

## Возможности

- Кнопка **«Открыть файл»** — выбор файла через системный файловый менеджер
  (Storage Access Framework, разрешения на хранилище не требуются).
- **Индикатор загрузки** во время чтения файла (чтение вынесено в фоновый поток).
- **Прокручиваемая область текста** с возможностью выделения и копирования.
- **Обработка ошибок**: пустой файл, ошибка чтения, неверный FB2.
- **Поддержка FB2** (задание *) — из XML извлекаются параграфы, заголовки
  и разделы книги.
- Для `.txt` кроме UTF-8 есть fallback на Windows-1251 (старые файлы).
- Поддержка тёмной темы (DayNight).

## Как открыть в Android Studio

1. Запустите Android Studio.
2. `File → Open…` и выберите папку `TextReaderApp`.
3. Дождитесь синхронизации Gradle (Android Studio скачает Gradle 9.6.0 и зависимости).
4. Запустите на эмуляторе или устройстве (`Shift + F10`).

Минимальная версия Android: **API 24 (Android 7.0)**.

## Структура

```
app/src/main/java/com/example/textreader/
├── MainActivity.kt  — только точка входа (создаёт ReaderScreen)
├── ReaderScreen.kt  — UI: разметка, клики, отображение состояний
├── ScreenState.kt   — состояния экрана (загрузка/текст/ошибка)
├── FilePicker.kt    — системный выбор файла (SAF)
├── FileLoader.kt    — фоновое чтение файла (корутины)
├── UriExt.kt        — получение имени файла из Uri
└── BookParser.kt    — чтение .txt и разбор .fb2 (XmlPullParser)
app/src/main/res/layout/activity_main.xml — разметка экрана
```
